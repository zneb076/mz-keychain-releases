# Keychain Manager v4 — ไฟล์ติดตั้ง

โปรแกรมจัดการออเดอร์ + สร้างไฟล์ STL สำหรับร้าน Mz Keychain

## ดาวน์โหลด

เลือกไฟล์จาก [Releases ล่าสุด](../../releases/latest)

| เครื่อง | ไฟล์ |
|---|---|
| Mac (Apple Silicon) | `..._aarch64.dmg` |
| Windows | `..._x64-setup.exe` |

## ต้องมีในเครื่อง

[OpenSCAD](https://openscad.org/downloads.html) — ใช้สร้างไฟล์ STL
(แก้ path ได้ในหน้า ตั้งค่า ⚙️ ของโปรแกรม)

## หมายเหตุ

- ไฟล์ไม่ได้ซื้อใบรับรองเซ็นชื่อ ครั้งแรกที่เปิด Windows จะเตือน SmartScreen
  (More info → Run anyway) และ Mac ให้คลิกขวาที่แอป → Open
- ติดตั้งแล้วโปรแกรมจะแจ้งเตือนเองเมื่อมีเวอร์ชันใหม่

repo นี้เก็บแค่ไฟล์ติดตั้ง — ซอร์สโค้ดอยู่ที่ repo ส่วนตัว
